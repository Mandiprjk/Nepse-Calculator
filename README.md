# 📈💰📊🖩 NBSC – Nepse Buy/Sell Calculator

A simple and effective web-based calculator to compute **buy/sell price**, **profit/loss**, **capital gains tax (CGT)**, **commissions**, and more for the **Nepal Stock Exchange (NEPSE)**.

This tool is built to help Nepali investors calculate the **amount to be paid or received** when buying or selling shares, with options for investor type and share holding duration.

## 📦 Features

- 📊 Buy/Sell calculation for NEPSE
- 👥 Select Investor Type: Individual or Institutional
- 🗓️ Select Share Holding Duration
- 💰 Get detailed breakdown:
  - Amount Before Commission
  - DP Charge
  - SEBON Fee
  - Broker Commission
  - Capital Gains Tax
  - Return on Investment
  - Actual Price per Share
- 📱 Mobile-friendly responsive layout
- ⚠️ Disclaimer: Bank charges are not included
